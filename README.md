# 娟娟生日网站（GitHub Pages 版）

把这个文件夹里的 `index.html` 传到 GitHub 就能上线。

`index.html` 是单文件：24 张照片和《告白气球》音乐都已经嵌在里面了，不用再传别的图片或音频。

## 上传步骤（网页操作，不用装软件）

1. 打开 GitHub，右上角 + 号 → New repository。
2. Repository name 随便起，比如 `juanjuan`；选 **Public**（免费账号开 Pages 必须是公开仓库）；点 Create repository。
3. 点 "uploading an existing file"，把 `index.html` 拖进去（README.md 不用传也可以），点 Commit changes。
4. 进仓库的 Settings → 左侧 Pages → Branch 选 `main`，文件夹选 `/ (root)`，点 Save。
5. 等 1 分钟左右，刷新 Pages 页面，会出现网址：`https://你的用户名.github.io/juanjuan/`，打开就是生日网站。

注意：`index.html` 必须直接放在仓库根目录，不能放在文件夹里、也不能改名，否则页面只会显示仓库的 README。

## 音乐

- 打开页面后，点一下屏幕任意处，音乐就开始播，播完自动循环。
- 右上角有个音乐按钮：🔇 是关着，🎵 是开着，点一下开关。
- 浏览器不让音乐一打开就自动出声，所以必须点一下才会有声音。

## 注意

- GitHub Pages 是公开的：任何人拿到链接都能打开这个网站，照片、信和音乐都会被看到。确认要公开再传。
- 以后想改内容：改好 `index.html` 后重新上传覆盖，等一两分钟就生效。
